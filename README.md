# 🛍️ Retail Sales Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing retail sales data using MySQL to identify sales trends, customer purchasing behavior, and product category performance.

The objective is to solve real-world business questions using SQL queries and extract meaningful insights from retail transaction data.

## 🎯 Business Objectives

- Understand overall retail sales performance.
- Analyze customer purchasing behavior.
- Identify top-performing product categories.
- Explore monthly sales trends.
- Identify high-value customers.
- Analyze sales patterns across different time shifts.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **IDE:** MySQL Workbench

## 📂 Dataset Overview

The project uses a retail sales dataset containing the following attributes:

| Column | Description |
|---|---|
| transaction_id | Unique transaction identifier |
| sale_date | Date of transaction |
| sale_time | Time of transaction |
| customer_id | Customer identifier |
| gender | Customer gender |
| age | Customer age |
| category | Product category |
| quantity | Number of items purchased |
| price_per_unit | Price per item |
| cogs | Cost of goods sold |
| total_sale | Total transaction value |

## 📊 Business Questions Solved

1. Retrieve all transactions made on a specific date.
2. Identify clothing transactions with higher quantities during November 2022.
3. Calculate total sales and order counts for each category.
4. Find the average age of customers purchasing Beauty products.
5. Identify transactions with total sales greater than 1,000.
6. Analyze transactions by gender across product categories.
7. Identify the best-performing sales month for each year.
8. Find the top 5 customers based on total sales.
9. Calculate unique customers in each product category.
10. Categorize orders into Morning, Afternoon, and Evening shifts.
